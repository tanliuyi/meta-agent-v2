# Model selector icon sources

The SVG files added for the model selector were downloaded from the fixed `@lobehub/icons-static-svg@1.94.0` package. The package is published under the MIT license.

Source package: https://www.npmjs.com/package/@lobehub/icons-static-svg
Source repository: https://github.com/lobehub/lobe-icons
License: https://github.com/lobehub/lobe-icons/blob/main/LICENSE

Provider assets:

- `antgroup.svg`: https://unpkg.com/@lobehub/icons-static-svg@1.94.0/icons/antgroup.svg (used for the Ant Group-owned Ant Ling provider; no separate verified Ant Ling mark was available)
- `kimi.svg`: https://unpkg.com/@lobehub/icons-static-svg@1.94.0/icons/kimi.svg
- `moonshot.svg`: https://unpkg.com/@lobehub/icons-static-svg@1.94.0/icons/moonshot.svg
- `together.svg`: https://unpkg.com/@lobehub/icons-static-svg@1.94.0/icons/together.svg

Model assets:

- `gemini.svg`: https://unpkg.com/@lobehub/icons-static-svg@1.94.0/icons/gemini.svg
- `grok.svg`: https://unpkg.com/@lobehub/icons-static-svg@1.94.0/icons/grok.svg
- `meta.svg`: https://unpkg.com/@lobehub/icons-static-svg@1.94.0/icons/meta.svg
- `zhipu.svg`: https://unpkg.com/@lobehub/icons-static-svg@1.94.0/icons/zhipu.svg
- `cohere.svg`: https://unpkg.com/@lobehub/icons-static-svg@1.94.0/icons/cohere.svg

The other provider and model mappings reuse the existing local provider SVG files under `assets/providers/`. `radius` has no verified brand SVG in the selected source and therefore intentionally keeps the existing text fallback.
